One-time setup to connect your Google Calendar and Obsidian vault. Takes ~5 minutes.

STEP 1 — GOOGLE CALENDAR
1. Go to Google Cloud Console → Credentials
2. Create a project (or select existing)
3. + CREATE CREDENTIALS → OAuth client ID → Web application
4. Under "Authorized JavaScript origins" add:
https://YOUR_USERNAME.github.io and http://localhost
5. Under "Authorized redirect URIs" add the same URLs
6. Copy the Client ID
7. Go to API Library → enable Google Calendar API
8. Go to OAuth consent screen → Add yourself as test user
STEP 2 — OBSIDIAN VAULT
Vault name: exactly as shown in Obsidian's vault switcher (bottom-left). Folder: subfolder inside the vault where daily notes go.
STEP 3 — TIMEZONE
Your Client ID is stored only in this browser's localStorage. No server. No backend. No data collection.
